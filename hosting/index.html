Why run it with us

Questions people ask first

Can I change plans later?

Yes. Upgrades apply immediately and the billing difference is prorated. Downgrades take effect at the end of the current billing period.

What happens if a server goes down?

Every node is monitored continuously. If hardware fails, we move your server to another machine automatically and the panel shows the move in the event log.

Do you support modpacks and plugins?

Java and Bedrock are both supported. Modpacks, Bukkit, Spigot, Paper and Fabric install from the panel, and you have full file access over SFTP for anything we do not list.

How do backups work?

We take daily offsite snapshots on premium plans and above. You can restore any of the last seven from the panel, and download them if you want your own copy.

Do you offer refunds?

Yes, within 72 hours of the first payment on a new order. See the terms of service for the full conditions.
